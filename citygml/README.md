# citygml

Short-name compatibility package for `openbim-citygml`.

This package defines no independent API. It depends on exactly version 0.1.0 of
the canonical package and purely re-exports that API. The canonical 0.1.0 is a
reserved scaffold only and does not implement CityGML parsing, writing,
modeling, validation, schema support, or OGC conformance.

Depend on either `citygml` or `openbim-citygml`, not both directly.
