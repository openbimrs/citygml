# openbim-citygml

Canonical OpenBIM.rs package name for future CityGML work.

Version 0.1.0 is a **reserved scaffold only**. It exposes `PACKAGE_STATUS` and
provides no CityGML data model, parser, writer, serializer, validation, schema,
version/profile support, or OGC conformance claim.

The official standard entry point is the
[OGC CityGML page](https://www.ogc.org/standards/citygml/). No standards
artifacts are included in this package.
