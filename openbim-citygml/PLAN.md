# Canonical package plan

This file records possible future investigation, not promised functionality.

1. Select an explicit CityGML version, standard part, and encoding scope.
2. Determine model ownership and lossless/streaming requirements.
3. Establish licensed, provenance-recorded fixtures and conformance terminology.
4. Design bounded parsing and writing APIs before implementation.
5. Add tests and update capability claims only after behavior exists.

Version 0.1.0 intentionally implements none of these items.
